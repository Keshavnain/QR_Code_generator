# 📱 QR Code Generator

A simple and interactive QR Code Generator built using HTML, CSS and JavaScript.

The project allows users to enter text or a URL, select the QR code size, and generate a QR code instantly.

## 🚀 Features

- 🔗 Generate QR codes from text or URLs
- 📏 Select QR code size
- ⚡ Generate QR code instantly
- 📥 Download the generated QR code
- 🎨 Simple and modern user interface
- 🖱️ Easy-to-use controls

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
